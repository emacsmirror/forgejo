#+title: emacs-forgejo

Emacs front-end for [[https://forgejo.org][Forgejo]] instances, including Codeberg and
self-hosted servers. Browse issues and pull requests, write reviews,
manage notifications and submit changes through AGit-Flow. Views use a
local SQLite cache and refresh after synchronization.

* Installation and setup

Requires Emacs 29.1 or later with SQLite support and =keymap-popup=.
Install =forgejo= from [[https://elpa.gnu.org/packages/forgejo.html][GNU ELPA]] with =M-x package-install=, or:

#+begin_src emacs-lisp
(use-package forgejo
  :ensure t
  :custom
  (forgejo-hosts '(("https://codeberg.org"))))
#+end_src

Configure each instance by its full web URL. Keep tokens outside source
files: with the default auth-source settings, add an entry to
=~/.authinfo.gpg=:

#+begin_example
machine codeberg.org login YOUR_USERNAME password YOUR_TOKEN
#+end_example

The archive package may lag this checkout. For development, clone the
repository and use the development commands below. Loading a checkout
does not install it for future Emacs sessions.

* Usage

=M-x forgejo= opens the top-level menu. In a Git repository with a
configured Forgejo remote, =C-x v f= (=forgejo-vc=) opens the repository
menu. Use =h= in list and detail views for available actions.

Watch rules can poll repositories for matching issues and pull requests:

#+begin_src emacs-lisp
(require 'forgejo-watch)
(setq forgejo-watch-rules
      '("owner/repo"
        ("owner/another-repo" . "state:open label:bug")))
(forgejo-watch-mode 1)
#+end_src

=M-x forgejo-watch-list= shows watched items. Disable polling with
=(forgejo-watch-mode -1)=. Composition uses =gfm-mode= when available,
with =text-mode= as a fallback; customize =forgejo-markdown-mode= to
select another mode.

* Development

#+begin_src sh
make dev          # Compile, lint, compile tests and run ERT
nix flake check   # Run the same gate in an isolated Nix build
make test         # Compile and run ERT
make lint         # Fail on checkdoc diagnostics
make clean        # Remove generated bytecode and autoloads
#+end_src

The Makefile uses the pinned Nix development environment when Nix is
available. Without Nix, provide Emacs and its dependencies yourself;
=FORGEJO_ENV_WRAPPED=1= bypasses the Nix wrapper and =EMACS_CMD= selects
the batch command. This fallback does not verify the pinned environment.

To load saved sources into a running development Emacs with dependencies
installed:

#+begin_src sh
make load EMACSCLIENT='emacsclient --socket-name forgejo-dev'
#+end_src

Use a disposable daemon for tests, never failure injection in your daily
editor. =make load= sends one eval and stops on error or quit. It rebuilds
the declared maps while retaining their objects, so open watch, search,
issue, PR and review buffers keep working. Options and custom bindings
are preserved. The first reload conservatively keeps existing bindings;
subsequent reloads update unchanged defaults. Save modified source
buffers first.

Rollback covers package maps, the compose minor-mode dispatch entry and
retained buffer maps, not functions or arbitrary load-time effects.
After a failure, fix the source and reload the full package before
continuing. Active popup sessions should be closed before reloading.

Private machine settings belong in ignored =local.mk=, for example:

#+begin_src makefile
EMACSCLIENT = emacsclient --socket-name forgejo-dev
#+end_src

Nix uses the Git source rather than =path:= so ignored overrides are not
copied into the flake source. Add new build inputs to =admin/sources= and
source/test files to the Makefile's explicit lists before running Nix.

* Contributing

Keep changes focused, include a regression test and run =make dev=.
See =AGENTS.md= for architecture and data-safety conventions.
Contributions of roughly 15 lines or more require
[[https://www.gnu.org/prep/maintain/html_node/Copyright-Papers.html][FSF copyright assignment]]; see the
[[https://codeberg.org/thanosapollo/emacs-forgejo/issues/17][copyright assignment discussion]].
